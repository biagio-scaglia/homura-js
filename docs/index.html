HomuraJS

Motore di time-travel debugging e state history management ad alte prestazioni per JavaScript e TypeScript. Un'architettura a Grafo Aciclico Diretto (DAG) concepita come "Git for application state".

Risposta Diretta / TL;DR

HomuraJS e una libreria TypeScript zero-dependency che registra l'evoluzione dello stato come grafo ad albero immutabile. Consente di retrocedere nel tempo (rewind), avanzare (fast-forward), creare rami paralleli (branching) senza mai distruggere la cronologia passata/futura, confrontare due stati con diff semantico profondo e ispezionarli con DevTools integrati.

Grafo DAG Non Distruttivo

Ogni mutazione diverge in un ramo senza mai cancellare le linee temporali storiche precedenti.

Proxy Draft Immutabile

Modifica diretta tramite sintassi ergonomica con Copy-On-Write puro a zero dipendenze.

Diffing Strutturale Profondo

Algoritmo di confronto ricorsivo con tracciamento esatto dei percorsi semantici dot-path.

DevTools Completi

Visualizzatore di timeline, ispettore dello stato ad albero, comparatore diff e scrubber temporale.

Perche HomuraJS?

Nei gestori di stato tradizionali, la cronologia e gestita come uno stack lineare piatto. Quando si retrocede indietro nel tempo ed avviene una nuova modifica, tutti gli stati futuri vengono distrutti in modo irreversibile.

HomuraJS elimina questa limitazione memorizzando ogni transizione come nodo di un grafo ad albero (DAG). Quando si retrocede e si applica una modifica, il motore genera automaticamente un nuovo ramo parallelo, mantenendo intatta la storia passata e futura.

Installazione

Seleziona il tuo gestore di pacchetti preferito:

Terminal 
npm install @homura-js/core

Per integrare HomuraJS nel tuo framework UI preferito:

Vue 3

Guida Rapida

Inizializza un'istanza ed esegui mutazioni controllate nel tempo in poche righe:

quickstart.ts 
import { createHomura } from '@homura-js/core';

// 1. Inizializzazione istanza
const homura = createHomura({
  initialState: { contatore: 0, utente: 'Homura' }
});

// 2. Modifica tramite Bozza Proxy
homura.update(draft => {
  draft.contatore += 10;
}, { label: 'Incremento contatore' });

// 3. Viaggio nel tempo
homura.undo(); // Il contatore torna a 0
homura.redo(); // Il contatore torna a 10

console.log(homura.getState()); // { contatore: 10, utente: 'Homura' }

Gestione dello Stato & Immutabilita

HomuraJS garantisce l'immutabilita tramite Proxy Drafts basati su Copy-On-Write. All'interno della funzione update(draft => ...) puoi modificare le proprieta direttamente: il motore applichera le modifiche solo ai percorsi toccati, condividendo la struttura immutata con lo stato precedente.

mutations.ts 
// Modifica bozza diretta
homura.update(draft => {
  draft.utente = 'Akemi';
  draft.contatore += 5;
}, { label: 'Aggiornamento Utente' });

// Ritorno funzionale puro
homura.update(state => ({
  ...state,
  contatore: state.contatore + 1
}), { label: 'Incremento Funzionale' });

// Impostazione diretta stato
homura.setState({ contatore: 100, utente: 'Homura' }, { label: 'Reset Totale' });

Grafo DAG & Branching ("Git for State")

Ogni operazione produce un oggetto HistoryEntry<T> indicizzato nel grafo:

types.ts 
interface HistoryEntry<T> {
  id: string;
  parentId: string | null;
  childrenIds: string[];
  branchId: string;
  timestamp: number;
  label: string;
  state: T;
  metadata?: Record<string, unknown>;
}

Se retrocedi nella cronologia ed esegui un nuovo update, HomuraJS crea in automatico un nuovo ramo senza cancellare la storia precedente:

branching.ts 
// Retrocede a uno stato passato
homura.jumpTo("nodo-passato-id");

// Questa modifica apre un nuovo ramo 'branch-2'
homura.update(draft => {
  draft.utente = 'Linea Temporale B';
}, { label: 'Bivio Alternativo' });

// Elenco di tutti i rami
const rami = homura.getBranches();

// Cambio attivo di ramo
homura.switchBranch(rami[0].id);

Navigazione Temporale

Comandi deterministici per viaggiare lungo la cronologia:

Metodo Descrizione
homura.undo() Retrocede al nodo genitore precedente.
homura.redo() Avanza al nodo figlio successivo nel ramo attivo.
homura.rewind(N) Retrocede velocemente di N passi nella cronologia.
homura.fastForward(N) Avanza velocemente di N passi nella cronologia.
homura.jumpTo(entryId) Salta direttamente a qualsiasi nodo del grafo DAG.

Snapshot & Milestone

Crea segnalibri persistenti per salvare pietre miliari dell'applicazione e ripristinarle istantaneamente:

snapshots.ts 
// Creazione snapshot
const snap = homura.snapshot('Punto di Controllo Boss', { stage: 3 });

// Elenco snapshot
const lista = homura.getSnapshots();

// Ripristino immediato dello stato memorizzato
homura.restore(snap.id);

// Eliminazione snapshot
homura.deleteSnapshot(snap.id);

Motore di Diff Strutturale

Il motore pure-function identifica le differenze semantiche esatte tra due stati:

diff.ts 
import { diffStates } from '@homura-js/core';

const statoA = { eroe: { hp: 100, arma: 'Spada' }, oggetti: ['Pozione'] };
const statoB = { eroe: { hp: 75, arma: 'Spada Magica' }, oggetti: ['Pozione', 'Scudo'] };

const diff = diffStates(statoA, statoB);
console.log(diff);
// [
//   { path: ['eroe', 'hp'], type: 'changed', oldValue: 100, newValue: 75 },
//   { path: ['eroe', 'arma'], type: 'changed', oldValue: 'Spada', newValue: 'Spada Magica' },
//   { path: ['oggetti', 1], type: 'added', value: 'Scudo' }
// ]

Persistenza dei Dati

Adattatori pronti all'uso per salvare l'intero grafo in LocalStorage o in memoria con debouncing:

persistence.ts 
import { createHomura, LocalStorageAdapter } from '@homura-js/core';

const homura = createHomura({
  initialState: { settings: { theme: 'dark' } },
  persistence: {
    adapter: new LocalStorageAdapter('app_homura_state'),
    autoSave: true,
    debounceMs: 250
  }
});

// Salvataggio manuale
await homura.save();

// Caricamento manuale
await homura.load();

Integrazione React 18+

L'hook useHomura sfrutta le API native useSyncExternalStore garantendo assenza di tearing e rendering ottimale tramite selettori:

Contatore.tsx 
import { useHomura, HomuraDevTools } from '@homura-js/react';
import { homura } from './store';

export function Contatore() {
  // Sottoscrizione con selettore fine-grained
  const { state: contatore, update, undo, redo, canUndo, canRedo } = useHomura(
    homura,
    s => s.contatore
  );

  return (
    <div>
      <h1>Valore: {contatore}</h1>
      <button onClick={() => update(d => { d.contatore++; }, { label: 'Incremento' })}>+1</button>
      <button disabled={!canUndo} onClick={() => undo()}>Undo</button>
      <button disabled={!canRedo} onClick={() => redo()}>Redo</button>

      <HomuraDevTools homura={homura} position="floating" />
    </div>
  );
}

Integrazione Vue 3

Contatore.vue 
<template>
  <div>
    <h1>Valore: {{ state.contatore }}</h1>
    <button @click="incrementa">+1</button>
    <button :disabled="!canUndo" @click="undo">Undo</button>
  </div>
</template>

<script setup lang="ts">
import { useHomura } from '@homura-js/vue';
import { homura } from './store';

const { state, update, undo, canUndo } = useHomura(homura);

function incrementa() {
  update(d => { d.contatore++; }, { label: 'Incremento' });
}
</script>

Domande Frequenti (FAQ)

Che cos'e HomuraJS?

HomuraJS e una libreria JavaScript/TypeScript per il time-travel debugging e la gestione della cronologia dello stato basata su Grafi Aciclici Diretti (DAG), concepita come 'Git per lo stato dell'applicazione'.

In cosa differisce HomuraJS da un normale sistema Undo/Redo?

I sistemi standard di Undo/Redo usano uno stack lineare che distrugge permanentemente gli stati futuri quando si torna indietro e si applica una nuova modifica. HomuraJS crea rami paralleli (Branching) senza mai eliminare la cronologia passata o futura.

Quali framework UI supporta HomuraJS?

HomuraJS e framework-agnostic nel core (@homura-js/core) e include pacchetti dedicati con integrazioni native per React 18+ (@homura-js/react), Vue 3 (@homura-js/vue) e Vanilla JavaScript (@homura-js/vanilla).

Come si installa HomuraJS?

E possibile installare il core tramite npm install @homura-js/core oppure installare il meta-package unificato npm install @biagioscaglia/homurajs.

Riferimento Completo delle API

Metodo Parametri Ritorno Descrizione
getState() - T Restituisce l'albero di stato immutabile corrente.
update(updater, options?) (draft: T) => void, StateUpdateOptions HistoryEntry<T> Esegue una modifica bozza Copy-On-Write.
undo() - HistoryEntry<T> | null Retrocede al nodo genitore nella timeline.
redo() - HistoryEntry<T> | null Avanza al nodo figlio nel ramo attivo.
rewind(steps) number HistoryEntry<T> | null Retrocede velocemente di N passi.
fastForward(steps) number HistoryEntry<T> | null Avanza velocemente di N passi.
jumpTo(entryId) string HistoryEntry<T> Salta a qualsiasi nodo del grafo DAG.
snapshot(name?, metadata?) string, Record<string, unknown> Snapshot<T> Crea un segnalibro immutabile dello stato.
restore(snapshotId) string HistoryEntry<T> Ripristina lo stato memorizzato nello snapshot.
diff(entryA, entryB?) HistoryEntry | T, HistoryEntry | T DiffChange[] Calcola il diff ricorsivo strutturale profondo.
